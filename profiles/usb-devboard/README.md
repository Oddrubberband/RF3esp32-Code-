# USB devboard firmware

This directory contains the reviewed 4 MB USB devboard source for **RF3-NFEM-R3**. From the repository root run `pio run -d profiles/usb-devboard -e rf3_usb_fem`. Run its native tests with `pio test -d profiles/usb-devboard -e native`. The top-level source builds the 16 MB custom PCB.
