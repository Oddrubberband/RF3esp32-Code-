RF3 Field Desktop R24 for Windows x64

1. Extract the entire ZIP to a folder on your PC.
2. Open RF3Desktop.exe in the extracted folder. Keep the _internal folder beside it. No Python or PlatformIO installation is required.
3. Connect your RF3 board by USB. Close any serial monitor using its port. Select the board's USB COM port in the GUI and connect. Each endpoint uses the port on its own PC.
4. To try the controls without a board, open Practice.cmd.

R24 firmware enables create-only SPIFFS imports and explicit cancellation errors. Older firmware can still be used for supported operations. When a board lacks create-only upload, Test Mode verifies a matching stored file by reading it back. Automatic Reliable resume requires R23 or later firmware at both endpoints.

The custom ESP PCB reports the latest one-second battery voltage and the rolling four-interval mean. Switching file mode while listening sends RX or RXNOACK. Check the board-reported mode beneath the selector.

If Windows does not list a COM port, check the USB data cable and the board's USB-to-serial driver in Device Manager. Connection logs are saved under %LOCALAPPDATA%\RF3\logs.
